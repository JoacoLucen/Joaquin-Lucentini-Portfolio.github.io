TravelData NoSQL: Integración Multimodelo con MongoDB, Redis y Neo4j:

Este proyecto, desarrollado en la materia "Bases de Datos" en la UNLP, consistió en el diseño e implementación de un ecosistema de datos multimodelo para una plataforma ficticia de gestión de viajes. El desafío central fue garantizar la coherencia de los datos al distribuir la información en tres tecnologías distintas, utilizando Python como lenguaje integrador para realizar cargas masivas y manipulaciones complejas.

La arquitectura se dividió estratégicamente según la naturaleza de la información:

MongoDB (Documental): Utilizada para almacenar el núcleo de la aplicación, incluyendo perfiles de usuario, destinos turísticos con sus actividades, información de hoteles e historial de reservas confirmadas. Elegida por su flexibilidad para manejar esquemas no uniformes y su estructura orientada a documentos que se asemeja a los objetos de Python.

Redis (Clave-Valor): Implementada para gestionar datos de baja latencia en memoria RAM. Se utilizó para el almacenamiento de la caché de búsquedas, el registro de usuarios conectados mediante estructuras de Sets y la gestión de reservas temporales con tiempos de vida (TTL) definidos para limpieza automática.

Neo4j (Grafos): El motor principal para el sistema de recomendaciones. Utilicé el lenguaje Cypher para modelar y consultar relaciones entre usuarios (amistades) y sus interacciones con los destinos (visitas). Esto permitió resolver problemas complejos, como sugerir destinos que ni el usuario ni su círculo cercano han visitado aún.

Mediante el desarrollo de pipelines en Jupyter Notebooks, automaticé la ingesta masiva de datos y creé un módulo de consultas avanzadas que demuestra la interoperabilidad entre motores. Logré realizar procesos críticos como la eliminación sincronizada de usuarios en múltiples bases de datos y el análisis estadístico de los destinos más visitados.
